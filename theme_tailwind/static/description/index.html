Quick Installation

  1. Install the theme module from Odoo Apps (Odoo 19.0 or higher required)
  2. Go to Website → Configuration → Themes
  3. Select Tailwind Theme and click Use This Theme
  4. Customize content using the drag-and-drop website builder
  5. Publish and start attracting customers!
