Theme Base Tailwind
===================

Overview
--------

Theme Base Tailwind is a responsive website theme for Odoo 19.0 inspired by the
free **Base Tailwind** template published on ThemeWagon.  It provides a
professional design built with Tailwind CSS and integrates seamlessly with
Odoo’s website builder.  Key features include a full‑width hero section,
feature and services blocks, an about section, pricing tables, a portfolio
showcase, testimonials, client logos, a blog preview and a contact form.

Installation
------------

1. Copy the `theme_base_tailwind` folder into your Odoo addons path.
2. Update the Apps list and install the module.
3. From **Website → Configuration → Themes**, select **Theme Base Tailwind** and
   apply it to your website.

Customization
-------------

All the text and images in the home page are defined with QWeb
blocks and can be modified through the website editor.  Use the Odoo
builder to adjust colours, replace images or add additional sections
without writing code.  The module loads Tailwind CSS from a CDN, so you
can also include custom utility classes in your custom snippets if
needed.
