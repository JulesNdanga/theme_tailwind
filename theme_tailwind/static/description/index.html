Tailwind Theme

A modern, fully responsive Odoo website theme powered by Tailwind CSS. It delivers a sleek, professional look and feel while remaining easy to customize through the Odoo website builder.

Key Features

  • Full-width hero section with call-to-action buttons and decorative shapes.
  • Feature highlights section with icons and concise descriptions.
  • About & services pages showcasing your company mission and service offerings.
  • Pricing tables that are easy to edit in Odoo's website builder.
  • Portfolio/project showcase with hover overlays and call-to-action buttons.
  • Testimonials and client logos to build trust with visitors.
  • Blog section highlighting your latest posts.
  • Contact & enquiry form pre-configured for quick integration.
  • Responsive design that adapts to desktops, tablets and mobile devices.

How to Use

  1. Install the module on your Odoo instance (minimum version 19.0).
  2. From the Website > Configuration > Themes menu, select Tailwind Theme and click Apply.
  3. Navigate to the Website Builder to edit text, images and pricing plans. All sections are created with editable blocks for easy customization.
  4. Publish your website and enjoy your new design!
